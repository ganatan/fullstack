# Copie distante SCP

Commandes essentielles pour copier des fichiers avec SSH.

## Copier vers un serveur

```bash
scp fichier.txt utilisateur@serveur:/tmp/
```

## Copier depuis un serveur

```bash
scp utilisateur@serveur:/tmp/fichier.txt .
```

## Copier un répertoire

```bash
scp -r dossier utilisateur@serveur:/tmp/
```

## Utiliser un port SSH spécifique

```bash
scp -P 2222 fichier.txt utilisateur@serveur:/tmp/
```

## Copier avec rsync

```bash
rsync -av dossier/ utilisateur@serveur:/tmp/dossier/
```

## Afficher la progression

```bash
rsync -av --progress dossier/ utilisateur@serveur:/tmp/dossier/
```
