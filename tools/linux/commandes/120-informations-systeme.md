# Informations système

Commandes essentielles pour identifier un système Linux.

## Noyau Linux

```bash
uname -a
```

## Version du noyau

```bash
uname -r
```

## Distribution

```bash
cat /etc/os-release
```

## Nom de la machine

```bash
hostname
```

## Informations détaillées

```bash
hostnamectl
```

## Durée de fonctionnement

```bash
uptime
```

## Date et heure

```bash
date
timedatectl
```

## Architecture

```bash
uname -m
```
