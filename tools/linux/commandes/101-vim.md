# Vim

Vim est un éditeur de texte en ligne de commande très utilisé sous Linux.

## Ouvrir un fichier

```bash
vim fichier.txt
```

## Modes principaux

- `i` : mode insertion
- `Esc` : revenir en mode commande

## Sauvegarder et quitter

```text
:w
:q
:wq
:q!
```

- `:w` : sauvegarder
- `:q` : quitter
- `:wq` : sauvegarder et quitter
- `:q!` : quitter sans sauvegarder

## Commandes utiles

```text
dd
yy
p
u
/search
```

- `dd` : supprimer une ligne
- `yy` : copier une ligne
- `p` : coller
- `u` : annuler
- `/texte` : rechercher du texte

## Navigation

```text
gg
G
0
$
```

- `gg` : début du fichier
- `G` : fin du fichier
- `0` : début de ligne
- `$` : fin de ligne
