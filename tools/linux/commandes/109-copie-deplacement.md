# Copie et déplacement

Commandes essentielles pour copier, déplacer et renommer des fichiers.

## Copier un fichier

```bash
cp fichier.txt copie.txt
```

## Copier dans un répertoire

```bash
cp fichier.txt archive/
```

## Copier un répertoire

```bash
cp -r projet projet-backup
```

## Conserver les attributs

```bash
cp -a projet projet-backup
```

## Déplacer un fichier

```bash
mv fichier.txt archive/
```

## Renommer un fichier

```bash
mv fichier.txt nouveau.txt
```

## Déplacer ou renommer un répertoire

```bash
mv projet ~/projects/
mv ancien nouveau
```
