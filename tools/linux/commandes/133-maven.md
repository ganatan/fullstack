# Maven

Commandes essentielles pour construire un projet Java avec Maven.

## Version

```bash
mvn -version
```

## Nettoyer

```bash
mvn clean
```

## Compiler

```bash
mvn compile
```

## Tests

```bash
mvn test
```

## Créer le package

```bash
mvn package
```

## Installer dans le repository local

```bash
mvn install
```

## Build complet

```bash
mvn clean install
```

## Arbre des dépendances

```bash
mvn dependency:tree
```
