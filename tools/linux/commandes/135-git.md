# Git

Commandes essentielles pour travailler avec Git.

## Version

```bash
git --version
```

## Initialiser un repository

```bash
git init
```

## Cloner

```bash
git clone URL
```

## Statut

```bash
git status
```

## Ajouter les modifications

```bash
git add .
```

## Commit

```bash
git commit -m "message"
```

## Pull et push

```bash
git pull
git push
```

## Historique et différences

```bash
git log --oneline
git diff
```
