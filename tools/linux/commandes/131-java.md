# Java

Commandes essentielles pour utiliser Java sous Linux.

## Version Java

```bash
java -version
```

## Version du compilateur

```bash
javac -version
```

## Localiser Java

```bash
which java
```

## JAVA_HOME

```bash
echo $JAVA_HOME
```

## Compiler une classe

```bash
javac HelloWorld.java
```

## Exécuter une classe

```bash
java HelloWorld
```

## Exécuter un JAR

```bash
java -jar application.jar
```

## Propriétés JVM

```bash
java -XshowSettings:properties -version
```
