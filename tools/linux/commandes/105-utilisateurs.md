# Utilisateurs

Commandes essentielles pour identifier et gérer les utilisateurs sous Linux.

## Utilisateur courant

```bash
whoami
```

## Informations utilisateur

```bash
id
```

## Utilisateurs connectés

```bash
who
```

Vue plus détaillée :

```bash
w
```

## Groupes

```bash
groups
```

Groupes d'un utilisateur :

```bash
groups utilisateur
```

## Changer d'utilisateur

```bash
su utilisateur
```

Passer en root :

```bash
su -
```

## Exécuter en administrateur

```bash
sudo commande
```

Ouvrir un shell administrateur :

```bash
sudo -i
```

## Mot de passe

```bash
passwd
```

Changer le mot de passe d'un utilisateur :

```bash
sudo passwd utilisateur
```
