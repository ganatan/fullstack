# SVN

Commandes essentielles pour travailler avec Subversion.

## Version

```bash
svn --version
```

## Checkout

```bash
svn checkout URL
```

## Statut

```bash
svn status
```

## Mettre à jour

```bash
svn update
```

## Voir les différences

```bash
svn diff
```

## Ajouter un fichier

```bash
svn add fichier.txt
```

## Commit

```bash
svn commit -m "message"
```

## Annuler les modifications

```bash
svn revert fichier.txt
```
