# Archives TAR et ZIP

Commandes essentielles pour créer et extraire des archives.

## Créer une archive TAR

```bash
tar -cf archive.tar dossier
```

## Extraire une archive TAR

```bash
tar -xf archive.tar
```

## Créer une archive TAR.GZ

```bash
tar -czf archive.tar.gz dossier
```

## Extraire une archive TAR.GZ

```bash
tar -xzf archive.tar.gz
```

## Créer un ZIP

```bash
zip -r projet.zip projet
```

## Extraire un ZIP

```bash
unzip projet.zip
```

## Lister le contenu d'un ZIP

```bash
unzip -l projet.zip
```
