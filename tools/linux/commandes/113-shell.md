# Shell

Commandes essentielles pour utiliser le shell Linux.

## Afficher le shell courant

```bash
echo $SHELL
```

## Lancer Bash

```bash
bash
```

## Lancer un script

```bash
bash script.sh
```

## Recharger la configuration Bash

```bash
source ~/.bashrc
```

ou :

```bash
. ~/.bashrc
```

## Alias

```bash
alias
alias ll='ls -la'
unalias ll
```

## Quitter le shell

```bash
exit
```
