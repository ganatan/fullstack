# Historique

Commandes essentielles pour retrouver les commandes déjà exécutées.

## Afficher l'historique

```bash
history
```

## Rechercher une commande

```bash
history | grep java
history | grep mvn
```

## Réexécuter la dernière commande

```bash
!!
```

## Réexécuter une commande par numéro

```bash
!123
```

## Recherche interactive

```text
Ctrl + R
```

## Effacer l'écran

```bash
clear
```

Raccourci :

```text
Ctrl + L
```
