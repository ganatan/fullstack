# Répertoires

Commandes essentielles pour gérer les répertoires sous Linux.

## Créer un répertoire

```bash
mkdir projet
```

## Créer plusieurs niveaux

```bash
mkdir -p projects/java/demo
```

## Lister le contenu

```bash
ls
ls -la
```

## Afficher l'arborescence

```bash
tree
tree src
```

## Supprimer un répertoire vide

```bash
rmdir dossier
```

## Supprimer un répertoire

```bash
rm -r dossier
rm -rf dossier
```

## Taille d'un répertoire

```bash
du -sh dossier
```
