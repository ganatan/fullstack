# CPU

Commandes essentielles pour consulter l'utilisation du processeur.

## Informations CPU

```bash
lscpu
```

## Nombre de processeurs disponibles

```bash
nproc
```

## Utilisation en temps réel

```bash
top
```

## Interface améliorée

```bash
htop
```

## Charge système

```bash
uptime
```

## Trier les processus par CPU

```bash
ps aux --sort=-%cpu
```

## Informations noyau

```bash
uname -a
```
