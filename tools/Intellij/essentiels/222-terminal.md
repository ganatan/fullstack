# Terminal intégré

IntelliJ possède un terminal intégré permettant d'exécuter les commandes du projet.
Il évite de changer constamment de fenêtre.

## Ouvrir

```text
View
→ Tool Windows
→ Terminal
```

Raccourci fréquent :

```text
Alt + F12
```

## Exemples

```bash
mvn test
git status
docker ps
java -version
```

## Répertoire

Le terminal s'ouvre généralement à la racine du projet.

## Shell

Le shell dépend du système :

```text
bash
zsh
PowerShell
cmd
WSL
```
