# Code Style

Code Style définit les règles de présentation appliquées par IntelliJ.
Chaque langage peut avoir ses propres règles de formatage.

## Configuration

```text
Settings
→ Editor
→ Code Style
```

## Java

```text
Java
```

Paramètres fréquents :

```text
Tabs and Indents
Spaces
Wrapping and Braces
Blank Lines
Imports
```

## Export

Les règles peuvent être stockées dans le projet.

```text
.idea/codeStyles
```

## Objectif

Tous les développeurs doivent idéalement obtenir le même formatage à partir du même code.
