# Diff et Merge

IntelliJ fournit des outils visuels pour comparer et fusionner des fichiers.
Ils sont particulièrement utiles lors des conflits Git.

## Diff

```text
Git
→ Show Diff
```

## Comparer deux fichiers

```text
Compare Files
```

## Conflit

IntelliJ affiche généralement :

```text
Left
Result
Right
```

## Actions

```text
Accept Left
Accept Right
Apply
Ignore
```

## Terminal

```bash
git diff
git status
```

Toujours relire le fichier résultat après résolution d'un conflit.
