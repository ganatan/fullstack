# Quick Fix

Quick Fix propose automatiquement une correction ou une action contextuelle.
C'est l'un des raccourcis les plus utiles d'IntelliJ.

## Raccourci

```text
Alt + Enter
```

## Exemples

```text
importer une classe
créer une méthode
implémenter une interface
ajouter un cast
supprimer du code inutile
convertir une syntaxe
```

## Exemple

Sur :

```java
List<Person> persons;
```

si `List` n'est pas importé :

```text
Alt + Enter
→ Import class
```

Toujours vérifier la correction proposée avant de l'accepter.
