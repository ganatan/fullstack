# Profiler

Le profiler permet d'analyser CPU, mémoire et performances d'une application.
Il aide à identifier méthodes lentes, allocations excessives et consommation anormale.

## Accès

Selon l'édition et la configuration :

```text
Run
→ Profile
```

## Mesures

```text
CPU
Memory
Allocations
Threads
```

## Cas d'usage

```text
méthode lente
boucle coûteuse
allocation massive
fuite mémoire
```

## Avant d'optimiser

Toujours mesurer :

```text
profiling
metrics
logs
benchmark
```

Éviter les optimisations basées uniquement sur une intuition.
