# Breakpoints

Un breakpoint arrête l'exécution sur une ligne précise.
Il permet d'inspecter l'état de l'application au moment exact du passage.

## Ajouter

Cliquer dans la marge gauche du fichier.

## Supprimer

Cliquer de nouveau sur le breakpoint.

## Breakpoint conditionnel

Clic droit sur le breakpoint :

```text
Condition
```

Exemple :

```java
person.id() == 10
```

## Breakpoint désactivé

Un breakpoint peut être temporairement désactivé sans être supprimé.

## Voir tous les breakpoints

```text
Ctrl + Shift + F8
```
