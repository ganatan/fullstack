# Navigation dans le code

IntelliJ permet de naviguer rapidement entre classes, méthodes et déclarations.
Ces fonctions font gagner énormément de temps dans les gros projets.

## Aller à une classe

```text
Ctrl + N
```

## Aller à un fichier

```text
Ctrl + Shift + N
```

## Aller à un symbole

```text
Ctrl + Alt + Shift + N
```

## Aller à la déclaration

```text
Ctrl + B
```

ou :

```text
Ctrl + clic
```

## Revenir en arrière

```text
Ctrl + Alt + Left
```
