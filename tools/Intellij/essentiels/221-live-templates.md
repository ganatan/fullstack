# Live Templates

Les Live Templates permettent d'insérer rapidement des structures de code répétitives.
Ils évitent de retaper manuellement les mêmes patterns.

## Exemple Java

Tapez :

```text
psvm
```

puis :

```text
Tab
```

Selon la configuration, IntelliJ peut générer une méthode `main`.

## Autres exemples

```text
fori
sout
```

## Configuration

```text
Settings
→ Editor
→ Live Templates
```

## Template personnalisé

On peut créer un raccourci pour générer :

```java
public static final String
```

Les Live Templates sont utiles pour standardiser le code récurrent.
