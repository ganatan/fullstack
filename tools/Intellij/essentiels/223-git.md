# Git

IntelliJ intègre Git pour visualiser les modifications et exécuter les opérations courantes.
Le repository Git reste indépendant de l'IDE.

## Statut

Fenêtre :

```text
Git
```

## Commit

```text
Ctrl + K
```

## Push

```text
Ctrl + Shift + K
```

## Pull

```text
Git
→ Pull
```

## Diff

Cliquer sur un fichier modifié pour afficher les différences.

## Terminal

```bash
git status
git diff
git log --oneline
```

Les commandes Git restent utiles pour comprendre ce que fait l'IDE.
