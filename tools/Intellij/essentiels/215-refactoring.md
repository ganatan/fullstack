# Refactoring

IntelliJ fournit des refactorings automatiques qui modifient le code sans casser les références.
Il vaut mieux les utiliser que faire des remplacements manuels.

## Rename

```text
Shift + F6
```

## Extract Method

```text
Ctrl + Alt + M
```

## Extract Variable

```text
Ctrl + Alt + V
```

## Extract Field

```text
Ctrl + Alt + F
```

## Change Signature

```text
Ctrl + F6
```

## Refactor menu

```text
Ctrl + Alt + Shift + T
```

Toujours exécuter les tests après un refactoring important.
