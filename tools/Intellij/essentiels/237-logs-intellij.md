# Logs IntelliJ

IntelliJ écrit ses propres logs pour diagnostiquer erreurs IDE, plugins et indexation.
Ils sont utiles lorsque l'IDE se comporte de manière anormale.

## Ouvrir les logs

```text
Help
→ Show Log in Explorer
```

ou selon le système :

```text
Show Log in Finder
Show Log in Files
```

## Fichier principal

```text
idea.log
```

## Rechercher

```text
ERROR
WARN
Exception
```

## Utilité

```text
plugin défaillant
erreur d'indexation
problème JVM IDE
erreur interne
```
