# Settings et configuration

Les Settings regroupent la majorité des options IntelliJ.
Il faut connaître leur emplacement pour adapter rapidement l'IDE à un environnement client.

## Ouvrir

Windows / Linux :

```text
Ctrl + Alt + S
```

## Sections importantes

```text
Editor
Plugins
Build Tools
Version Control
Tools
Appearance
Keymap
```

## Rechercher un réglage

Utiliser la barre de recherche des Settings.

Exemples :

```text
Maven
Gradle
Java Compiler
Annotation Processing
HTTP Proxy
Terminal
```

## Configuration projet

Pour les paramètres liés au projet :

```text
File
→ Project Structure
```
