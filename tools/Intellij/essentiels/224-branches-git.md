# Branches Git

IntelliJ permet de créer, changer et fusionner des branches Git.
La barre d'état affiche généralement la branche courante.

## Voir les branches

Cliquer sur le nom de la branche en bas à droite.

## Nouvelle branche

```text
New Branch
```

## Changer de branche

```text
Checkout
```

## Merge

```text
Merge into Current
```

## Terminal

```bash
git branch
git switch feature
git switch -c feature
git merge feature
```

Toujours vérifier les modifications locales avant de changer de branche.
