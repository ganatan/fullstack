# Formatage du code

IntelliJ peut reformater automatiquement le code selon les règles configurées.
Cela garantit une présentation homogène du projet.

## Reformater

```text
Ctrl + Alt + L
```

## Optimiser les imports

```text
Ctrl + Alt + O
```

## Reformater un fichier

```text
Code
→ Reformat Code
```

## Reformater une sélection

Sélectionner le code puis :

```text
Ctrl + Alt + L
```

## Configuration

```text
Settings
→ Editor
→ Code Style
```

Le formatage ne doit pas modifier la logique du programme.
