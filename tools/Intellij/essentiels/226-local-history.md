# Local History

Local History conserve localement certaines modifications effectuées dans IntelliJ.
Il peut permettre de récupérer du code même sans commit Git.

## Accès

Clic droit sur un fichier ou dossier :

```text
Local History
→ Show History
```

## Utilisations

```text
retrouver du code supprimé
comparer deux versions locales
restaurer une modification
```

## Important

Local History ne remplace pas Git.

```text
Git
→ historique durable

Local History
→ filet de sécurité local
```

Ne jamais compter uniquement sur Local History pour sauvegarder un projet.
