# Coverage

La couverture mesure les lignes ou branches exécutées pendant les tests.
IntelliJ peut afficher directement les zones couvertes dans l'éditeur.

## Exécuter avec couverture

Clic droit sur un test :

```text
Run with Coverage
```

## Résultats

Les lignes sont indiquées comme :

```text
couvertes
partiellement couvertes
non couvertes
```

## Utilité

```text
identifier du code non testé
vérifier les cas oubliés
améliorer une suite de tests
```

## Important

100 % de couverture ne garantit pas que les tests sont pertinents.
