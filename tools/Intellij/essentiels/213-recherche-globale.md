# Recherche globale

IntelliJ permet de rechercher du texte dans tout le projet.
C'est indispensable pour retrouver une constante, une requête, une URL ou un appel métier.

## Recherche globale

```text
Ctrl + Shift + F
```

## Remplacement global

```text
Ctrl + Shift + R
```

## Rechercher partout

```text
Shift
Shift
```

## Limiter la recherche

On peut filtrer par :

```text
Project
Module
Directory
Scope
File mask
```

## Exemple File mask

```text
*.java
```

ou :

```text
*.xml
```
