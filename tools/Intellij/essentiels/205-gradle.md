# Gradle

IntelliJ intègre Gradle pour importer et exécuter les tâches du projet.
Le fichier `build.gradle` ou `build.gradle.kts` reste la source de vérité.

## Fenêtre Gradle

```text
View
→ Tool Windows
→ Gradle
```

## Recharger

```text
Reload All Gradle Projects
```

## Tâches courantes

```text
build
test
clean
classes
```

## Terminal

```bash
./gradlew build
```

## Vérifier les dépendances

```bash
./gradlew dependencies
```

Après modification du build, synchroniser le projet Gradle.
