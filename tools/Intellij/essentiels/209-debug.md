# Debug

Le mode Debug permet d'exécuter l'application en contrôlant son déroulement.
Il permet d'arrêter le programme, inspecter les variables et exécuter du code à la volée.

## Lancer en Debug

```text
Run
→ Debug
```

ou utiliser l'icône :

```text
🐞
```

## Actions principales

```text
Resume
Step Over
Step Into
Step Out
Run to Cursor
```

## Raccourcis courants

```text
F8       Step Over
F7       Step Into
Shift+F8 Step Out
F9       Resume
```

Le debug est particulièrement utile pour suivre un flux métier complexe.
