# Code Completion

La complétion de code propose classes, méthodes, variables et snippets.
Elle réduit fortement la saisie manuelle et limite les erreurs de syntaxe.

## Complétion simple

```text
Ctrl + Space
```

## Complétion intelligente

```text
Ctrl + Shift + Space
```

## Compléter une instruction

```text
Ctrl + Shift + Enter
```

## Exemple

```java
person.
```

IntelliJ propose :

```text
id()
firstName()
lastName()
cityId()
```

La complétion dépend du type réellement connu par l'IDE.
