# Inspections

Les inspections IntelliJ détectent automatiquement erreurs, code mort et problèmes potentiels.
Elles complètent le compilateur et les outils comme Sonar ou Checkstyle.

## Inspection d'un fichier

```text
Analyze
→ Inspect Code
```

## Inspection du projet

Choisir :

```text
Whole project
```

## Exemples détectés

```text
variable inutilisée
code inaccessible
null potentiel
condition toujours vraie
API dépréciée
```

## Configuration

```text
Settings
→ Editor
→ Inspections
```

Les inspections peuvent être activées, désactivées ou ajustées par niveau.
