# Plugins

Les plugins ajoutent ou étendent les fonctionnalités d'IntelliJ.
Ils peuvent fournir support de langage, frameworks, analyse ou intégration d'outils.

## Configuration

```text
Settings
→ Plugins
```

## Actions

```text
Install
Update
Disable
Uninstall
```

## Exemples

```text
Lombok
SonarLint
Rust
Docker
Kubernetes
```

## Prudence

Limiter le nombre de plugins :

```text
moins de consommation mémoire
moins de conflits
moins de surface de sécurité
```

Installer uniquement des plugins provenant de sources fiables.
