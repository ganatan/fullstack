# ISR

ISR signifie `In-Sync Replicas`.
Il s'agit des replicas suffisamment synchronisées avec le leader d'une partition.

## Exemple

```text
Leader : Broker 1

ISR :
Broker 1
Broker 2
Broker 3
```

Si Broker 3 prend trop de retard :

```text
ISR :
Broker 1
Broker 2
```

## Importance

Kafka préfère élire un nouveau leader parmi les replicas présentes dans l'ISR.

L'ISR joue donc un rôle central dans :

```text
disponibilité
durabilité
tolérance aux pannes
```
