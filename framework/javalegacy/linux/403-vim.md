# Découverte de Vim sous Linux

## Objectif

Apprendre les commandes essentielles de Vim afin de modifier rapidement un fichier texte sur un serveur Linux.

---

# 1. Vérifier que Vim est installé

Afficher la version :

```bash
vim --version
```

Si Vim est installé, la version est affichée.

---

# 2. Ouvrir un fichier

Créer ou ouvrir un fichier :

```bash
vim demo.txt
```

L'éditeur Vim s'ouvre.

---

# 3. Les modes de Vim

Vim possède principalement deux modes.

## Mode commande

C'est le mode par défaut.

Il permet de :

* se déplacer ;
* supprimer ;
* copier ;
* coller ;
* enregistrer ;
* quitter.

---

## Mode insertion

Il permet de saisir du texte.

Entrer en mode insertion :

```text
i
```

En bas de l'écran apparaît :

```text
-- INSERT --
```

---

# 4. Quitter le mode insertion

Appuyer sur :

```text
Esc
```

On revient en mode commande.

---

# 5. Enregistrer

Depuis le mode commande :

```text
:w
```

---

# 6. Quitter

```text
:q
```

---

# 7. Enregistrer et quitter

```text
:wq
```

ou

```text
ZZ
```

---

# 8. Quitter sans enregistrer

```text
:q!
```

---

# 9. Se déplacer

Déplacer le curseur :

```text
h
gauche

j
bas

k
haut

l
droite
```

Ou utiliser les flèches du clavier.

---

# 10. Aller au début ou à la fin

Début du fichier :

```text
gg
```

Fin du fichier :

```text
G
```

---

# 11. Supprimer

Supprimer un caractère :

```text
x
```

Supprimer une ligne :

```text
dd
```

Supprimer cinq lignes :

```text
5dd
```

---

# 12. Copier

Copier une ligne :

```text
yy
```

Copier trois lignes :

```text
3yy
```

---

# 13. Coller

Coller sous la ligne :

```text
p
```

---

# 14. Annuler

Annuler la dernière modification :

```text
u
```

---

# 15. Refaire

Refaire la modification :

```text
Ctrl + r
```

---

# 16. Rechercher

Rechercher un mot :

```text
/texte
```

Suivant :

```text
n
```

Précédent :

```text
N
```

---

# 17. Numéros de ligne

Afficher les numéros :

```text
:set number
```

Masquer :

```text
:set nonumber
```

---

# 18. Les commandes indispensables

```text
i       insertion
Esc     retour au mode commande

:w      enregistrer
:q      quitter
:wq     enregistrer et quitter
:q!     quitter sans enregistrer

dd      supprimer une ligne
yy      copier une ligne
p       coller

u       annuler

gg      début du fichier
G       fin du fichier

/texte  rechercher
```

---

# Résumé

Ouvrir un fichier :

```bash
vim demo.txt
```

Entrer en mode insertion :

```text
i
```

Quitter le mode insertion :

```text
Esc
```

Enregistrer :

```text
:w
```

Quitter :

```text
:q
```

Enregistrer et quitter :

```text
:wq
```

Quitter sans enregistrer :

```text
:q!
```

Pour un développeur Java intervenant sur un serveur Linux, ces commandes couvrent l'immense majorité des besoins quotidiens : modifier un fichier de configuration, corriger un script Shell ou consulter rapidement un fichier texte.
