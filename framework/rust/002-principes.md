# Outils Rust

rustup	            Gestionnaire de Rust
                    Il installe, met à jour et permet de changer de version (stable, beta, nightly).

rustc	            Compilateur Rust

cargo	            L'outil officiel pour créer des projets
                    gérer les dépendances, compiler, exécuter et tester.

Toolchain stable	La version stable complète du compilateur et 
                    de la bibliothèque standard (std).

rust-std	        La bibliothèque standard de Rust, utilisée par la plupart des programmes.

# Cargo est l'outil officiel de Rust. C'est à la fois :

un gestionnaire de projets ;
un gestionnaire de dépendances ;
un outil de compilation ;
un outil de tests.
