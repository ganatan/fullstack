# Nombres

Types numériques principaux en Rust.

## Entiers signés

```rust
let a: i32 = 10;
let b: i64 = 20;
```

## Entiers non signés

```rust
let a: u32 = 10;
let b: usize = 20;
```

## Flottants

```rust
let price: f64 = 19.99;
```

## Opérations

```rust
let sum = 10 + 5;
let sub = 10 - 5;
let mul = 10 * 5;
let div = 10 / 5;
let rem = 10 % 3;
```

## Conversion

```rust
let value = 10_i32;
let converted = value as i64;
```
