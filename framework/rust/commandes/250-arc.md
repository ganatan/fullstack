# Arc

`Arc<T>` permet de partager une valeur entre plusieurs threads.

## Création

```rust
use std::sync::Arc;

let value = Arc::new(10);
```

## Cloner la référence

```rust
let value2 = Arc::clone(&value);
```

## Avec un thread

```rust
use std::thread;

let value = Arc::new(String::from("Rust"));
let shared = Arc::clone(&value);

let handle = thread::spawn(move || {
    println!("{shared}");
});

handle.join().unwrap();
```

## Avec Mutex

```rust
use std::sync::{
    Arc,
    Mutex,
};

let value = Arc::new(Mutex::new(0));
```
