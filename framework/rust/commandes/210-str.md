# str

`&str` représente une vue empruntée sur une chaîne UTF-8.

## Littéral

```rust
let name: &str = "Rust";
```

## Depuis String

```rust
let name = String::from("Rust");
let slice: &str = &name;
```

## Paramètre de fonction

```rust
fn display(name: &str) {
    println!("{name}");
}
```

## Tester si vide

```rust
let empty = name.is_empty();
```

## Contient un texte

```rust
let contains = name.contains("us");
```

## Commence par

```rust
let starts = name.starts_with("Ru");
```
