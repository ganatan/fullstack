# For

Boucle `for` en Rust.

## Parcourir une plage

```rust
for i in 0..5 {
    println!("{i}");
}
```

## Inclure la borne finale

```rust
for i in 1..=5 {
    println!("{i}");
}
```

## Parcourir un tableau

```rust
let values = [10, 20, 30];

for value in values {
    println!("{value}");
}
```

## Parcourir par référence

```rust
for value in &values {
    println!("{value}");
}
```

## Index et valeur

```rust
for (index, value) in values.iter().enumerate() {
    println!("{index} {value}");
}
```
