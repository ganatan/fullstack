# Map

`map` transforme chaque élément d'un iterator.

## Exemple

```rust
let values = vec![1, 2, 3];

let result: Vec<i32> = values
    .iter()
    .map(|x| x * 2)
    .collect();
```

Résultat :

```text
[2, 4, 6]
```

## Transformation de String

```rust
let names = vec!["rust", "java"];

let result: Vec<String> = names
    .iter()
    .map(|name| name.to_uppercase())
    .collect();
```
