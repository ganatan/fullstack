# Use

`use` importe des éléments dans le scope courant.

## Import simple

```rust
use std::collections::HashMap;
```

## Plusieurs imports

```rust
use std::collections::{
    HashMap,
    HashSet,
};
```

## Alias

```rust
use std::io::Result as IoResult;
```

## Import interne

```rust
use crate::person::Person;
```

## Parent

```rust
use super::Person;
```

## Réexport

```rust
pub use person::Person;
```
