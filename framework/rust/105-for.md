# Utilisation de la boucle `for` en Rust

La boucle `for` permet de parcourir une plage de nombres, une collection ou un itérateur.  
Chaque exemple peut être utilisé directement dans le fichier `src/main.rs`.

Exécution :

```bash
cargo run
```

---

## 1. Parcourir une plage de nombres

La syntaxe `0..5` parcourt les nombres de `0` à `4`.  
La valeur située à droite de `..` est exclue.

```rust
fn main() {
    for nombre in 0..5 {
        println!("{nombre}");
    }
}
```

Résultat :

```text
0
1
2
3
4
```

---

## 2. Parcourir une plage inclusive

La syntaxe `1..=5` parcourt les nombres de `1` à `5`.  
L’opérateur `..=` inclut la valeur finale.

```rust
fn main() {
    for nombre in 1..=5 {
        println!("{nombre}");
    }
}
```

Résultat :

```text
1
2
3
4
5
```

---

## 3. Parcourir un tableau

Une boucle `for` peut parcourir directement les valeurs d’un tableau.  
À chaque itération, la variable reçoit l’élément courant.

```rust
fn main() {
    let nombres = [10, 20, 30, 40];

    for nombre in nombres {
        println!("{nombre}");
    }
}
```

Résultat :

```text
10
20
30
40
```

---

## 4. Parcourir un vecteur par référence

L’opérateur `&` permet de parcourir un vecteur sans le déplacer.  
Le vecteur reste utilisable après la boucle.

```rust
fn main() {
    let langages = vec!["Rust", "Java", "TypeScript"];

    for langage in &langages {
        println!("{langage}");
    }

    println!("Nombre de langages : {}", langages.len());
}
```

Résultat :

```text
Rust
Java
TypeScript
Nombre de langages : 3
```

---

## 5. Récupérer l’index avec `enumerate`

La méthode `enumerate()` fournit l’index et la valeur de chaque élément.  
L’index commence à zéro.

```rust
fn main() {
    let langages = ["Rust", "Java", "TypeScript"];

    for (index, langage) in langages.iter().enumerate() {
        println!("{index} : {langage}");
    }
}
```

Résultat :

```text
0 : Rust
1 : Java
2 : TypeScript
```

---

## 6. Parcourir une plage dans l’ordre inverse

La méthode `rev()` inverse l’ordre de parcours d’un itérateur.  
Elle est souvent utilisée pour créer un compte à rebours.

```rust
fn main() {
    for nombre in (1..=5).rev() {
        println!("{nombre}");
    }

    println!("Départ");
}
```

Résultat :

```text
5
4
3
2
1
Départ
```

---

## 7. Parcourir une plage avec un pas

La méthode `step_by()` permet de choisir l’écart entre deux valeurs.  
Dans cet exemple, seuls les nombres pairs sont parcourus.

```rust
fn main() {
    for nombre in (0..=10).step_by(2) {
        println!("{nombre}");
    }
}
```

Résultat :

```text
0
2
4
6
8
10
```

---

## 8. Parcourir les caractères d’une chaîne

La méthode `chars()` retourne les caractères Unicode d’une chaîne.  
Elle permet de parcourir correctement les caractères accentués.

```rust
fn main() {
    let texte = "école";

    for caractere in texte.chars() {
        println!("{caractere}");
    }
}
```

Résultat :

```text
é
c
o
l
e
```

---

## 9. Modifier les éléments d’un vecteur

La méthode `iter_mut()` fournit une référence mutable vers chaque élément.  
Elle permet de modifier les valeurs directement dans le vecteur.

```rust
fn main() {
    let mut nombres = vec![10, 20, 30];

    for nombre in nombres.iter_mut() {
        *nombre *= 2;
    }

    println!("{nombres:?}");
}
```

Résultat :

```text
[20, 40, 60]
```

---

## 10. Utiliser `continue` et `break`

Le mot-clé `continue` passe directement à l’itération suivante.  
Le mot-clé `break` interrompt complètement la boucle.

```rust
fn main() {
    for nombre in 1..=10 {
        if nombre == 3 {
            continue;
        }

        if nombre == 8 {
            break;
        }

        println!("{nombre}");
    }
}
```

Résultat :

```text
1
2
4
5
6
7
```

---

# Points essentiels

- `debut..fin` exclut la valeur finale ;
- `debut..=fin` inclut la valeur finale ;
- `for` peut parcourir une plage, un tableau, un vecteur ou une chaîne ;
- `&collection` évite de déplacer la collection ;
- `iter()` fournit des références immuables ;
- `iter_mut()` fournit des références mutables ;
- `enumerate()` fournit l’index et la valeur ;
- `rev()` inverse l’ordre du parcours ;
- `step_by()` définit un pas ;
- `continue` ignore l’itération courante ;
- `break` arrête la boucle.
